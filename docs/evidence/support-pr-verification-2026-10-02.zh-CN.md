# TableSync 英文使用助手：PR 验证报告

日期：2026-10-02（America/New_York）。基线：`origin/main` 的 `ce1798c90c5baa722208d76fc0d32899f2dd41ed`。分支：`codex/english-support-assistant`。

## 结论与范围

当前助手适合回答 TableSync 的邀请、饮食偏好、菜单投票、购物分工、Potluck、分享和房间有效期问题。界面、回答和帮助条目使用英文；默认运行本地知识模式，明确显示没有连接 AI 模型。

在当前主线功能契约下，84 道固定问题经独立逐题阅读完整回答和来源，得到 **84 通过、0 部分通过、0 失败**。正确说明“当前未支持”也算回答正确，不能理解成实现了该功能。这组题的预期曾用于修复，不能称为盲测、总体 100% 准确率或真实 AI 模型质量证明。

本 PR 只包含助手、必要的全局入口、测试、说明和合成验证证据。原工作区尚未发布的菜单、购物和账号试验改动保留在原位置。

## 能回答的问题

| 英文问题示例 | 经过验证的回答内容 |
| --- | --- |
| How do I invite friends? | 从房间复制邀请链接；来宾无需主持人账号；区分邀请链接与只读 Share 链接。 |
| Will changing the menu update my shopping list? | 主持人可 Revise menu，保留已有投票和当前清单；重新 Finalize 后保留匹配分工和足量采购，增加数量需重新检查。 |
| What about items already bought? | 在明确的菜单上下文中解释已购状态与数量覆盖；无上下文时先询问细节。 |
| How do we split the shopping? | 解释主持人分配、来宾认领/释放、Purchased 权限、自动保存及 Retry save。 |
| How does Budget comfort affect automatic shopping assignments? | 自动分配计入 Potluck 承诺，不适配预算的项目留为 Unassigned；手动或保留的分配可能超额，估价不是结账封顶。此新增问题还通过专项单测和实际界面检查。 |
| How long does a gathering last? | 创建后 7 天与预约聚餐后 72 小时取较晚者；区分房间保留期与浏览器来宾会话。 |
| How do I invite friends and remove groceries I already have? | 同时回答邀请任务与当前购物编辑限制，并提供两个相关来源。 |

同主题追问可继续；插入天气、体育等无关问题会结束此前主题。菜单修订上下文中的“Explain more” 已验证可展开操作步骤。

## 明确的能力边界

- 当前 main 没有单道菜替换、直接修改份数、个人食谱录入、手动增删/恢复购物项或可复用菜单模板。助手明确说明限制，并给出现有的整套菜单修订等替代流程。
- 助手解释操作步骤，不能代发邀请、删除房间、购买物品或读取实时房间/私人账号数据。
- 对指南未记录的 PDF 导出或自动短信，不猜测按钮。可解释如何记录饮食备注，不提供过敏治疗或用药建议。
- 可选 Responses 接口有超时、并发限制和知识回退；本次只验证模拟提供商行为，没有调用真实模型，也没有验证真实模型的质量、费用或延迟。

本地全量单元测试按原有 5 秒限时运行，结果为 **897 通过、1 超时、1 跳过（899 项）**。超时位于未修改的 `test-auth-environment.test.ts`，发生在首次加载真实认证依赖；单独运行以及降低并发后仍能复现。以 15 秒限时做额外诊断时，两项认证断言均通过（约 10 秒总时长）。该诊断没有改测试文件，也不计为默认限时的全量通过。PR 的 GitHub CI 仍应独立检查默认限时、数据库回归与完整端到端流程。

本机浏览器复验在上述超时后中断。Firefox 的复合问题和手机项分别超时于 page/context 建立阶段，未执行功能或 axe 断言；首项停在等待回答，WebKit 停在页面加载及 hydration 前。同期可用内存约 757 MB（总内存约 16.9 GB），但不能据此断定失败原因。实际页面的同一菜单问题可正常回答，来源重复展开也已手动确认。保留这些结果，PR 先以草稿提交，等待标准 CI 的独立验证；没有放宽断言或限时。

问题采集遇到一次共享的 60 次/分钟额度，采集脚本遵守 Retry-After 后完成，未改变或跳过测试。延迟字段不包括等待限流窗口的时间，也不代表真实 AI 模型延迟。
